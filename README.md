# User Persona WorldForge

SillyTavern third-party extension for generating USER Personas from structured options and World Info.

## Features

- USER Persona generator
- QUICK / STANDARD / DEEP generation modes
- English machine-readable persona keys
- World Info source selection
- World Info entry analysis into modules such as factions, characters, locations, systems, items and rules
- Select/lock world modules before generation
- Generate a persona that is adapted to the selected world modules
- Preview/edit generated persona
- Import generated text into SillyTavern's native Persona system when the installed SillyTavern version exposes the compatible Persona commands/API

## Install

In SillyTavern:

1. Open **Extensions**.
2. Open **Install Extension**.
3. Paste this repository URL:
   `https://github.com/YOUR_GITHUB_NAME/UserPersonaWorldForge`
4. Install.
5. Refresh the SillyTavern page.

SillyTavern downloads third-party extensions directly from Git repositories.

## Important

This extension is third-party software. Review the source before installing it. The extension does not require a separate server plugin.

## Development

The current package is intentionally dependency-free and can be loaded directly by SillyTavern.
