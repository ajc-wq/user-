# User Persona WorldForge

SillyTavern 第三方扩展：中文界面、英文内部 Persona 模板、World Info 模块化分析、USER Persona 生成与原生 Persona 导入。

## 安装
SillyTavern → Extensions → Install Extension → 粘贴 GitHub 仓库地址。

## 说明
- 界面全部中文；英文仅用于生成结果中的机器可读字段名。
- 当前版本重点是 USER Persona；CHAR 页签暂未开放。
- World Info 可拆为势力、人物、地点、修炼/能力体系、物品、规则、历史等模块。
- 可勾选条目、使用模块、锁定模块；锁定模块会作为生成硬约束。
